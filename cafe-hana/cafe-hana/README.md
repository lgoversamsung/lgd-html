# cafe hana

‘하루에 하나, 나를 위한 느긋한 시간’을 주제로 만든 가상의 동네 카페 랜딩페이지입니다. 따뜻한 크림색과 올리브색, 햇살이 드는 공간 사진으로 편안한 분위기를 구성했습니다.

## 실행

`index.html`을 웹 브라우저에서 열면 됩니다. 별도 설치, 빌드, JavaScript, 외부 폰트 또는 API 연결이 필요하지 않습니다. 사진도 폴더에 포함되어 있어 인터넷 연결 없이 볼 수 있습니다.

## 파일 구성

- `index.html`: 브랜드 문구, 대표 메뉴, 이야기, 운영 시간과 주소
- `style.css`: 색상, 글꼴, 여백, 데스크톱·태블릿·모바일 배치
- `images/cafe-window.png`: 첫 화면의 창가 사진
- `images/signature-menu.png`: 세 가지 대표 메뉴 사진
- `images/cafe-interior.png`: 브랜드 이야기의 공간 사진
- `images/favicon.svg`: 브라우저 탭 아이콘

## 수정하기

1. 문구와 메뉴 가격은 `index.html`의 각 구역에서 수정합니다.
2. 대표 색상과 글꼴은 `style.css` 맨 위 `:root`에서 변경합니다. 기기에 설치된 기본 글꼴을 사용하므로 운영체제에 따라 글자 모양이 약간 달라집니다.
3. 사진을 교체할 때는 같은 파일명을 사용하거나 HTML의 `src`를 변경합니다. 메뉴 사진은 한 장의 가로 사진을 CSS로 세 영역으로 나눠 보여줍니다. 개별 사진으로 변경하려면 `.menu-photo img`의 너비를 `100%`, 위치를 `left: 0`으로 변경하세요.
4. 모바일 배치는 CSS 하단의 `@media` 구역에서 수정합니다.

상단 메뉴, 메뉴 보기, 방문 안내, 맨 위로 링크는 해당 페이지 영역으로 이동합니다. 실제 주문·예약·지도 서비스는 연결하지 않았습니다. 주소, 가격, 운영 시간은 모두 창작한 예시입니다.

## 이미지 제작

사진 세 장은 내장 이미지 생성 도구로 이 프로젝트를 위해 제작했습니다. 실제 매장 사진이 아닙니다. 제작 방향은 다음과 같습니다.

- 창가: 작은 한국 동네 카페, 참나무 창틀, 초록 정원, 리넨 커튼, 햇살과 그림자, 도자기 라테 잔과 소금빵.
- 메뉴: 크림색 배경 위 크림 라테·버터 소금빵·말차 라테를 가로로 배치한 자연광 음식 사진.
- 공간: 아이보리 벽, 목재 테이블과 의자, 에스프레소 바, 식물, 정원으로 열린 문이 있는 아담한 카페.

사진 속 문구나 로고 없이 제작했고, 페이지의 제목과 메뉴 등은 모두 수정 가능한 HTML 텍스트입니다.
